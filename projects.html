What's inside this build.

A breakdown of the moving parts: the gesture engine, the camera lifecycle, and the technologies chosen to keep everything fast and simple.

Featured Project

Hands-Free Navigation Engine

🖐️

Hand tracking

A lightweight, browser-based hand-landmark model detects a palm reference point on every video frame, entirely on-device.

📈

Gesture classification

Plain arithmetic — dominant-axis comparison and threshold checks — turns landmark movement into scroll or swipe actions. No second model involved.

🧊

Smoothing & cooldown

Exponential smoothing removes jitter; a short cooldown window stops one long gesture from firing multiple page changes.

Technology

Built with a deliberately small stack

HTML5

Semantic markup shared across all five pages.

CSS3

One stylesheet: custom properties, grid, and lightweight transitions.

Vanilla JavaScript

No build step, no bundler, no framework runtime.

MediaPipe Tasks Vision

A compact, browser-compatible hand-landmark model running fully client-side.

getUserMedia API

Native browser webcam access with careful lifecycle management.

Static hosting

Any local HTTP server is enough — no backend, no database.

Project Structure

Clean, separated responsibilities

hand-gesture-utility.js

A standalone, drop-in engine: camera lifecycle, hand tracking, smoothing, gesture classification, and the state machine, all in one file with a small public API (enable(), disable(), .on(...)). Copy it into any project.

navigation.js

Owns the single source of truth for page order, navbar highlighting, and page transitions.

config.js

Site-specific settings — debug mode, page transitions, and any overrides passed into the gesture utility. Nothing is a magic number buried in logic.

app.js

Wires the utility's gesture events to this site's UI: the Hands-Free toggle, status panel, and swipe-to-navigate behavior.
