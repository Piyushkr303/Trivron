About Trivron

Built to prove interfaces can stay simple.

We believe the browser is capable of far more than most sites ask of it. Trivron is a small demonstration: a normal website, built with plain web technology, that adds hands-free control without becoming a heavy application.

🎯

Our Mission

Show that accessible, camera-based interaction can be built with plain HTML, CSS, and JavaScript — no bloated frameworks or cloud AI required.

🧭

Our Approach

Every feature starts from the lightest possible implementation. We add complexity only when a simpler approach genuinely cannot do the job.

🤝

Our Values

Privacy first, performance always, and an interface that never breaks when the fancy parts fail.

Timeline

How this project came together

  • Phase 1–2

    Multi-page website & navigation

    Five content pages sharing one navbar and one centrally-defined page order.

  • Phase 3–5

    Hands-Free UI, camera, hand tracking

    A floating toggle requests the webcam and loads a lightweight on-device hand landmark model.

  • Phase 6–9

    Smoothing, scroll, swipe, cooldown

    Raw landmark jitter is smoothed, movement is classified as vertical or horizontal, and a cooldown prevents runaway page changes.

  • Phase 10–13

    Feedback, performance, polish

    Visual status, debug overlay, edge-case testing, and a clean project structure ready to read and extend.
